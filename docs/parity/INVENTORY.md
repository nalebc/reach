# Agent capabilities: Mac implementation and Windows route

Implementation inventory, updated Oct 14 2026. Paths relative to the repo; tests drop `.test.mjs`. Plan and runner evidence: `docs/WINDOWS_AGENT_PARITY.md`. The Mac references below describe the original audit; their line numbers can move.

**Today on Windows:** browser sign-in, invite links, the public start page, agent gateway and hosted MCP are enabled by capability detection through the private keyed Tailscale route. Background mode, sleep prevention, the PC's terminals and native H.264 are built. B/C/E/F are merged into the integration branch: all four presets are offered through detected private helpers; native admission, screen/input, Files, shell and pause tests pass. The owner's point probe and field map also pass. The Files broker is proven under a standard account on GitHub's Windows runner; AppContainer jobs cannot start in that runner's synthetic standard-user desktop and still need acceptance in an owner's interactive Windows session. No physical Windows PC or real phone has been tested.
