# Mac and Windows: full parity audit

## Summary

Six sweeps (gates, ui, routes, tests, journeys, claims) produced 170 verified findings. Merged by root cause, they come to **50 items**: 2 blocks-use, 15 confirmed major, 7 unproven major and 26 minor. None of them is already in `docs/parity/INVENTORY.md`, the workstream table of `docs/WINDOWS_AGENT_PARITY.md`, or the recently fixed list.

**How impact was set.** Each sweep's impact is replaced by its verifier's narrower reading wherever the verifier gave one. The majority of those readings decides, and a tie goes to the higher level. Within a level, confirmed items come before unproven ones, then items are ordered by how many Windows users hit them.

**What breaks first on Windows:**
- **No phone path starts a new Claude Code session.** The chat start refuses every drive-letter folder (#1). The terminal route types a quoted path that PowerShell only echoes (#6), probably a regression from `00a358e1` ("CLIs start by full path").
- **A PC without Git for Windows fails at the first message** (#7).
- **Codex chats probably can't connect at all** (#2).
- **The PC is not kept available.** It sleeps (#3), nothing starts Reach at sign-in (#4), and a lock ends the live screen instead of dimming it (#5).
- **Security holes that fail open:**
  - a guest's live screen is unmasked (#12);
  - a guest can read a concealed clipboard (#13);
  - Codex pipes are trusted unchecked (#17);
  - Reach writes into Claude chats another process holds (#8), against the fail-closed rule for agent readers.
- **The `AGENTS.md` restart and "one Reach per computer" rules don't hold** (#10, #11).
- **Proof is thin.** The Windows lane runs 34 of 497 test files (#21).

**Do first; small and with no dependencies:**
- #1 (one line);
- #6 (`powershellCall` in the terminal route);
- #12 and #13 (refuse non-owner screen viewing and clipboard reads on Windows);
- #8 (sends fail closed, hand-over refused);
- #14 (hide Team and fix its text).

**Still to establish on a real PC:**
- where the Windows Claude app keeps its session records (#9);
- what Codex reports as `socketPath` (#2);
- whether current Claude Code still needs Git Bash (#7);
- what `CopyFromScreen` does on the lock screen (#5);
- whether npm hits EBUSY when it updates over a running Reach (#10);
- PowerShell 5.1 output encoding in jobs (#23).

**Path conventions.** A bare `index.mjs` is `server/index.mjs`. `agent-sessions/` is `server/agent-sessions/`. Other bare `.mjs` files are in `server/`. `.tsx` and `.ts` files are in `src/`, and `.test.mjs` files are in `test/`. `scripts/` and `docs/` are named in full.
